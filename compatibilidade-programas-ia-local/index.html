Roda no meu aparelho?

Programas, sistemas e formatos de modelo: o que roda em cada tipo de computador.

Nível Essencial8 min de leitura22 links para fontesAtualizado em 25/11/2026

Nível de leitura

Em poucas palavras

Antes de instalar qualquer coisa, confira se o programa roda no seu aparelho. Escolha o tipo de computador e veja o que funciona, o que pede ajustes e o que não tem suporte, com o caminho mais simples para começar.

Analogia: é como conferir a tomada antes de viajar: o aparelho é bom, mas precisa do adaptador certo.

Qual é o seu aparelho?

Por onde começar: Comece pelo LM Studio ou pelo Ollama; para imagens, o ComfyUI Desktop.

Atenção neste aparelho

  • Docker no Mac não usa a placa de vídeo. No Docker Desktop, a placa de vídeo só chega aos contêineres no Windows com WSL2, e só com placa NVIDIA. No Mac, instale os programas de IA direto no sistema.
  • Mac não roda CUDA. Programas que exigem placa NVIDIA, como o TensorRT-LLM e boa parte das ferramentas de vídeo e de treino, não rodam no Mac. Para texto, o Mac tem caminho próprio: MLX, Ollama e LM Studio.
  • Mac com processador Intel. O LM Studio não roda em Mac com processador Intel. Este guia trata só dos Macs com chip Apple, do M1 em diante.
  • Docker no Mac não usa a placa de vídeo. No Docker Desktop, a placa de vídeo só chega aos contêineres no Windows com WSL2, e só com placa NVIDIA. No Mac, instale os programas de IA direto no sistema.
  • Placa AMD no Windows: comece pelo Vulkan. Para conversar com modelos, LM Studio e Ollama funcionam pelo Vulkan. Imagens e ferramentas em Python dependem do PyTorch da AMD para Windows, que cobre as placas mais novas; confira a lista da AMD antes de comprar. No Linux o suporte é mais completo.
  • GB10 é Linux em processador ARM. O DGX Spark e as caixas com o mesmo chip rodam o DGX OS, um Linux para ARM. Programas de Windows e contêineres feitos só para processadores x86 não rodam. A NVIDIA publica guias oficiais de Ollama, LM Studio, vLLM e ComfyUI para ele.
  • O Ollama pode ignorar a GPU integrada. Em notebooks e mini PCs com Radeon integrada, o Ollama pode deixar a GPU de lado e usar só o processador. Ligue-a com a variável OLLAMA_IGPU_ENABLE=1 ou use o LM Studio.
  • Processador sem AVX2. No Windows e no Linux x64, o LM Studio exige processador com a instrução AVX2. Pentium e Celeron antigos podem não ter; confira na ficha do processador.
