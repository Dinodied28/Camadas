Glossário

Os termos da plataforma, do mais básico ao mais técnico. As barras mostram o nível de cada um.

Nível Essencial3 min de leitura

36 termos

Agente
Programa em que o modelo trabalha em vários passos usando ferramentas, como ler arquivos e rodar comandos.
API compatível com OpenAI
Jeito padrão de conversar com um servidor de modelos. A maioria dos aplicativos e agentes usa.
Cache de contexto (KV)
Memória que guarda o texto já lido na conversa. Cresce com o tamanho do contexto; em 8 bits ocupa metade.
CGNAT
Quando o provedor divide o mesmo endereço de internet entre muitos clientes. Impede abrir portas para acessar a máquina de fora.
Chamada de ferramenta
Quando o modelo pede para executar algo, como buscar um arquivo. É a base dos agentes.
Client Hints
Dados que os navegadores baseados no Chromium (Chrome, Edge, Opera) entregam quando o site pede: versão do sistema, arquitetura do processador e modelo do celular.
Cluster
Várias máquinas ligadas para funcionar como uma só. Soma memória; a velocidade sobe menos.
Contexto
Quanto texto o modelo considera de uma vez, em tokens. É a memória de curto prazo da conversa.
CUDA
A plataforma de software da NVIDIA. Quase todo programa de IA roda nela primeiro.
Denso
Modelo que usa todos os parâmetros a cada token. Mais lento para o tamanho que tem.
GGUF
Formato de arquivo de modelo usado pelo llama.cpp, pelo Ollama e pelo LM Studio.
GPU
A parte do chip feita para muitas contas ao mesmo tempo. É ela que roda a IA.
IA do sistema
Modelo que já vem no celular, como o Apple Intelligence e o Gemini Nano. Os apps usam sem baixar nada, mas você não escolhe o modelo.
IA local
Inteligência artificial que roda no seu próprio computador, sem depender de uma empresa na internet.
Leitura do prompt
Tempo que o modelo leva para ler tudo o que você mandou antes de começar a responder. Em inglês, prefill.
LPDDR
Tipo de memória de celulares e notebooks finos. A LPDDR5X de 2025 entrega cerca de 77 GB/s num celular; a LPDDR6 chega a 127 GB/s.
Memória unificada
Quando processador e GPU dividem a mesma memória, como nos Macs e nas caixas GB10. Permite modelos grandes.
MLX
Biblioteca da Apple para rodar modelos nos chips M, com formato de arquivo próprio.
Modelo aberto
Modelo cujos arquivos qualquer pessoa pode baixar e rodar. Também chamado de modelo de pesos abertos.
MoE (mistura de especialistas)
Modelo dividido em especialistas; a cada token, só alguns trabalham. Ocupa muita memória e responde rápido.
Motor
Programa que carrega o modelo e gera as respostas: llama.cpp, Ollama, MLX, vLLM.
MTP
Previsão de vários tokens de uma vez. Um modelo auxiliar adivinha as próximas palavras e o principal confere, o que acelera a geração.
MXFP4
Formato de 4 bits em que o GPT-oss é distribuído.
NPU
Parte do chip dedicada a IA em notebooks e celulares. Boa para tarefas leves; os modelos grandes ainda rodam na GPU.
Parâmetros
Os números que formam o modelo, contados em bilhões (B). Guardam o que ele aprendeu.
Parâmetros ativos
A parte de um modelo MoE usada a cada token. É ela que define a velocidade.
Q4_K_M
Quantização de cerca de 4,8 bits por parâmetro no formato GGUF; a mais usada.
Quantização
Guardar cada parâmetro com menos bits para o modelo ocupar menos memória, como comprimir uma foto.
RAG
Técnica de ligar o modelo a documentos: ele busca trechos relevantes antes de responder.
RDMA
Acesso direto à memória de outra máquina pela rede, sem passar pelo processador. Torna os clusters mais rápidos.
Tailscale
Rede privada que liga seus aparelhos pela internet sem abrir portas no roteador.
tok/s
Tokens por segundo: a velocidade da resposta. Abaixo de 10 é lento; acima de 60, rápido para agentes.
Token
Pedaço de palavra que o modelo lê e escreve. Em português, cerca de três quartos de uma palavra.
Vazão de memória
Quantos gigabytes por segundo a memória entrega ao chip. É o que mais limita a velocidade de geração.
VRAM
A memória da placa de vídeo. Num PC, só ela é rápida o bastante para o modelo.
WebGPU
Interface que deixa uma página usar a placa de vídeo para cálculos. O Raio-X usa para medir a vazão da memória.
